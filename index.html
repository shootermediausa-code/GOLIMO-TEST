GO LIMO

Test versions of the rider app, the driver app and the admin & dispatch website. Open them on your phone. When the page asks to use your location, tap Allow so the map starts where you are.

Rider app →Book a ride on a real Dallas–Fort Worth map. Test cars drive on real roads. Driver app →Sign up, upload documents, get approved, then take test ride requests. Tap the TODAY amount for daily and weekly earnings. Admin & dispatch (computer) →The back office: live map, dispatch, drivers and documents, rides, customers, payouts, prices, zones, staff. Sample data, sign-in is filled in. Sign-in code for testing is 0000. Payments are test only. Each page runs its own test copy of the system, so the rider and driver pages don't see each other until the live server is set up.
